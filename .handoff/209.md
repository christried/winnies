## Summary

Closes #209. Only adding a Challenge checked the limit of 50 Challenges on a Winnie; duplicating gave a 51st. The duplicate route now checks the same limit, with the same 429 and message.

```diff
 POST /api/challenges/:id/duplicate
   not the Owner's Challenge          → 403
+  findChallengeWinnieId(id)          → 404 when gone
+  assertChallengeQuota(winnieId)     → 429 "A Winnie can hold 50 Challenges."
   duplicateChallenge(id)
```
