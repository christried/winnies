## Summary

Closes #210. Un-winning lowered the Counter of every Challenge sent a non-won status, Won or not. Only a Won Challenge's Counter has something to reverse now.

```diff
 unwinChallenge(id)
   status: active when it has time, else todo
-  count:  Target > 0                 → Target − 1, else count
+  count:  was Won and Target > 0     → Target − 1, else count
```
