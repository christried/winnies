Winnies Design System · Phase 4

Motion language

Three tiers, Ambient, Responsive and Celebratory, all on everywhere at full strength. The dialect sets the character: Workspace is calm enough for hours, Broadcast is loud and legible, Showcase is maximal. Every recipe animates only transform, opacity and filter. Reduced motion stops everything and keeps each end state readable.

Sound cues

No audio files yet. Everything is muted by default. Settings will offer Off, UI sounds, and UI + ticks, so ticks are opt-in. Sounds are not motion, so they still play under reduced motion, at the state change (0ms) instead of the sync point. Overlay sounds go out through a separate, opt-in browser source, and tick sounds never reach the stream.
