# Screenshots

Static captures of every screen state for orientation, 174 images. Named `{frame ID}-{state}-{mode}.jpg`; the IDs match `01-screen-index.md`.

How they were made: each state was rendered from the real prototype (`reference/prototype/`) at its design width (1440, or 1920 × 1080 for the Overlay), scaled to **924 px wide** and stitched top to bottom, so tall pages are complete. Captured with **reduced motion on**, so every animated state is shown at rest on its readable end state (e.g. the WON! stamp held, the Complete banner landed). Phase 6b frames have no reduced-motion switch and may catch an animation mid-way. For exact pixels, motion and interaction, open the prototype; these are a map, not the spec.

To regenerate: open `reference/prototype/_Screenshot Harness.dc.html` and call `__step(n)` for each tile listed in `_shots.js`.
