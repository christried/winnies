# Changelog

All notable changes to Winnies are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project, starting with the Beta, tries to follow the concepts of [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

**What's next?** Mostly decided on the fly. See [open issues on GitHub](https://github.com/christried/winnies/issues) to see what's being considered or [visit the GitHub Project](https://github.com/users/christried/projects/6) to see what's in development (or if anything is being developed).
Anyway, I'm very happy if you decide to [suggest an idea or report a bug here](https://github.com/christried/winnies/issues/new/choose).

## 0.9.0 - 2026-09-11

Beta. Not very finished but finished enough for Winnies being done on September 12 I hope.

### Added

- Sign in with Discord to access the app and keep your Winnies in your account.
- Create, rename, delete and switch between Winnies.
- Add challenges containing information about the game, win conditions and an optional counter.
- Edit a challenge inline or duplicate it, reset its timer or delete it.
- Pin challenges to keep them at the top and drag to reorder the rest.
- A lot of timers. Try to break them - hope you can't.
- Mark challenges as won (or un-won if you were a bit too quick).
- Share any Winnie through a permanent read-only link. The shared view refreshes on its own!
- A stream overlay: a compact version of the shared view for OBS browser sources.
- Confetti
